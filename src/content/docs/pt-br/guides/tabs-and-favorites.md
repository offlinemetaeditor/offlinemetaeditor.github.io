## Abas

Cada aba mostra uma conta com a sua própria visão: o nível, o que está selecionado em cada nível, a busca, o Show,
os filtros de coluna e a ordenação. Várias abas podem mostrar a mesma conta (uma edição feita numa aparece nas
outras) ou contas diferentes. Um **•** marca as abas cuja conta tem alterações pendentes.

- **➕** abre uma aba nova: a mesma conta, uma cópia desta aba, outra conta já baixada ou outra conta para
  baixar.
- Na janela **Accounts**, **Open in a new tab** define se uma conta abre numa aba nova ou na atual.
- Clique com o botão direito numa aba para renomear, duplicar, mover ou fechar a aba, ou para fechar as outras.
  Para fechar uma aba, clique nela com o botão do meio ou clique no **×** dela.
- Atalhos: <kbd>Ctrl</kbd>+<kbd>Tab</kbd> e <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> (ou
  <kbd>Ctrl</kbd>+<kbd>Page Down</kbd> e <kbd>Ctrl</kbd>+<kbd>Page Up</kbd>) vão para a próxima aba e para a
  anterior, <kbd>Alt</kbd>+<kbd>1</kbd> a <kbd>Alt</kbd>+<kbd>8</kbd> vão para uma aba específica,
  <kbd>Alt</kbd>+<kbd>9</kbd> vai para a última, e <kbd>Ctrl</kbd>+<kbd>W</kbd> fecha a aba.

As abas voltam quando você abre o editor de novo. Na abertura, só a conta da aba ativa é carregada; as outras
carregam quando você passa para elas.

## Favoritos

A barra de favoritos fica embaixo da barra de ferramentas (**Tools → Favorites bar** mostra ou esconde a barra).
Um favorito pode ser uma de duas coisas:

- **⭐ Itens selecionados**: as campanhas, os conjuntos de anúncios ou os anúncios que você selecionou. Ao abrir,
  ele mostra só esses itens e o que está dentro deles, com uma faixa avisando isso; **✖ show all** tira o limite.
  Com um favorito de uma só campanha aberto, **➕ New ad set** cria o conjunto nessa campanha.
- **🔖 Uma visão**: o nível, a campanha ou o conjunto de anúncios, o Show, a busca, os filtros de coluna e a
  ordenação.

Clique em **⭐ Add to favorites** para escolher um dos dois, ou pressione <kbd>Ctrl</kbd>+<kbd>D</kbd>: o atalho
salva a seleção ou, quando nada está selecionado, a visão.

Clique num favorito para abri-lo na aba atual (trocando de conta, se for preciso); <kbd>Ctrl</kbd>+clique ou
clique com o botão do meio abre o favorito numa aba nova. Clique com o botão direito nele para abrir numa aba
nova, substituir pela seleção ou pelos filtros atuais, renomear, mover ou excluir. Os favoritos de outras contas
mostram o nome da conta.
