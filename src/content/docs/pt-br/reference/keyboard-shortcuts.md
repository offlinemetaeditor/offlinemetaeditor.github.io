---
title: Atalhos de teclado
description: Todos os atalhos do editor. Eles seguem a referência rápida do Google Ads Editor, então as teclas que você já conhece fazem a mesma coisa aqui.
---

Os atalhos seguem os do [Google Ads Editor](https://support.google.com/google-ads/editor/answer/54654?hl=pt-BR),
então <kbd>Ctrl</kbd>+<kbd>T</kbd> baixa, <kbd>Ctrl</kbd>+<kbd>K</kbd> confere e <kbd>Ctrl</kbd>+<kbd>P</kbd>
envia. No editor, <kbd>F1</kbd> (ou **Help → Keyboard shortcuts**) mostra esta lista, e cada item dos menus
mostra a sua tecla.

## Baixar, conferir e enviar

| Teclas | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Abrir uma conta |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Adicionar uma conta em uma nova aba: uma já baixada ou uma direto da Meta |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Get recent changes: baixar da Meta (suas edições são mantidas) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | Get recent changes with more data: também pixels, conversões e públicos |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Check changes: a Meta valida as alterações e não aplica nada |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Post changes: mostra o que vai ser enviado; nada sai antes de você confirmar |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Importar um arquivo CSV |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Import from text: colar linhas |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Salvar agora (o editor também salva sozinho) |

## Buscar e editar

| Teclas | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Buscar nas linhas (nome ou id) |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Limpar a busca e os filtros |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Selecionar todas as linhas exibidas |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Make multiple changes: colar linhas de uma planilha |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Desfazer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> ou <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Refazer |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Reverter as alterações das linhas selecionadas |
| <kbd>Delete</kbd> | Excluir as linhas selecionadas (na Meta, quando você enviar) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Pausar as linhas selecionadas |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Ativar as linhas selecionadas |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copiar as linhas selecionadas (também como tabela, para uma planilha) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copiar só os nomes |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Recortar as linhas selecionadas: ao colar, elas são movidas |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Colar na campanha ou no conjunto de anúncios selecionado (linhas copiadas de uma planilha são importadas) |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Substituir texto nos nomes selecionados |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Acrescentar texto aos nomes selecionados |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>H</kbd> | Mudar as maiúsculas e minúsculas dos nomes selecionados |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Mudar os orçamentos das campanhas ou dos conjuntos de anúncios selecionados |

## Navegar

| Teclas | O que faz |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Linha de cima / de baixo (o painel Properties acompanha) |
| <kbd>Home</kbd> / <kbd>End</kbd> | Primeira / última linha |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | Uma página para cima / para baixo |
| <kbd>Shift</kbd> com qualquer uma das teclas acima | Selecionar as linhas no caminho |
| <kbd>Alt</kbd>+<kbd>←</kbd> | Subir um nível: anúncios → conjuntos de anúncios → campanhas |
| <kbd>Alt</kbd>+<kbd>→</kbd> | Descer um nível, para dentro das linhas selecionadas |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | Nível Campaigns / Ad sets / Ads |
| <kbd>F2</kbd> | Editar o nome da linha selecionada (em Properties) |

## Abas, favoritos e janelas

| Teclas | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Fechar a aba |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> ou <kbd>Ctrl</kbd>+<kbd>Page Down</kbd> | Próxima aba |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> ou <kbd>Ctrl</kbd>+<kbd>Page Up</kbd> | Aba anterior |
| <kbd>Alt</kbd>+<kbd>1</kbd> … <kbd>Alt</kbd>+<kbd>8</kbd> | Ir para a aba 1 … 8 |
| <kbd>Alt</kbd>+<kbd>9</kbd> | Ir para a última aba |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Adicionar aos favoritos (a seleção ou, quando nada está selecionado, a visualização) |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | A janela Settings |
| <kbd>F1</kbd> | A lista de atalhos |

## Mouse

| Ação | O que faz |
|---|---|
| <kbd>Ctrl</kbd>+clique, <kbd>Shift</kbd>+clique | Selecionar várias linhas; na árvore, adicionar ou remover uma campanha ou um conjunto de anúncios |
| Clique com o botão do meio em uma aba | Fechar a aba |
| <kbd>Ctrl</kbd>+clique em um favorito | Abrir o favorito em uma nova aba |
| Clique com o botão direito em uma aba ou em um favorito | Renomear, duplicar, mover, fechar… |

## Bom saber

- **Enquanto você digita em uma caixa**, <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd>,
  <kbd>Ctrl</kbd>+<kbd>C</kbd>/<kbd>X</kbd>/<kbd>V</kbd>, <kbd>Delete</kbd>, as setas, <kbd>Home</kbd>,
  <kbd>End</kbd> e <kbd>F2</kbd> agem sobre o texto. As outras (<kbd>Ctrl</kbd>+<kbd>T</kbd>,
  <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>Ctrl</kbd>+<kbd>H</kbd>…) continuam funcionando.
- Com um texto selecionado em Properties (um id, por exemplo), <kbd>Ctrl</kbd>+<kbd>C</kbd> copia esse texto.
- Durante um download ou um envio, só funcionam as teclas de consulta (buscar, navegar, copiar).
- Dois atalhos do Google Ads Editor ficam sem função aqui, porque a Meta não tem nada parecido: aceitar e
  rejeitar propostas (<kbd>Ctrl</kbd>+<kbd>[</kbd> e <kbd>Ctrl</kbd>+<kbd>]</kbd>) e alterar URLs
  (<kbd>Ctrl</kbd>+<kbd>U</kbd>; o link e os parâmetros de URL de um anúncio ficam em Properties).
