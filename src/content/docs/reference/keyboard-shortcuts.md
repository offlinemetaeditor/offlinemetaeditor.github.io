---
title: Keyboard shortcuts
description: Every shortcut of the editor and what each one does.
---

<kbd>Ctrl</kbd>+<kbd>T</kbd> downloads, <kbd>Ctrl</kbd>+<kbd>K</kbd> checks and <kbd>Ctrl</kbd>+<kbd>P</kbd>
posts. In the editor, <kbd>F1</kbd> (or **Help → Keyboard shortcuts**) shows this list, and every menu entry
shows its key.

## Download, check and post

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>O</kbd> | Open an account |
| <kbd>Ctrl</kbd>+<kbd>N</kbd> | Add an account in a new tab: a downloaded one, or one from Meta |
| <kbd>Ctrl</kbd>+<kbd>T</kbd> | Get recent changes: download from Meta (your edits are kept) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>T</kbd> | Get recent changes with more data: also pixels, conversions and audiences |
| <kbd>Ctrl</kbd>+<kbd>K</kbd> | Check changes: Meta validates them and applies nothing |
| <kbd>Ctrl</kbd>+<kbd>P</kbd> | Post changes: shows what will be sent; nothing goes before you confirm |
| <kbd>Ctrl</kbd>+<kbd>I</kbd> | Import a CSV file |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>I</kbd> | Import from text: paste rows |
| <kbd>Ctrl</kbd>+<kbd>S</kbd> | Save now (the editor also saves by itself) |

## Search and edit

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>F</kbd> | Search the rows (name or id) |
| <kbd>Ctrl</kbd>+<kbd>L</kbd> | Clear the search and the filters |
| <kbd>Ctrl</kbd>+<kbd>A</kbd> | Select every row shown |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>B</kbd> | Make multiple changes: paste rows from a spreadsheet |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Z</kbd> or <kbd>Ctrl</kbd>+<kbd>Y</kbd> | Redo |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>R</kbd> | Revert the changes of the selected rows |
| <kbd>Delete</kbd> | Delete the selected rows (on Meta when you post) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>P</kbd> | Pause the selected rows |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>A</kbd> | Activate the selected rows |
| <kbd>Ctrl</kbd>+<kbd>C</kbd> | Copy the selected rows (also as a table, for a spreadsheet) |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>C</kbd> | Copy just the names |
| <kbd>Ctrl</kbd>+<kbd>X</kbd> | Cut the selected rows: pasting moves them |
| <kbd>Ctrl</kbd>+<kbd>V</kbd> | Paste into the selected campaign or ad set (rows from a spreadsheet: import them) |
| <kbd>Ctrl</kbd>+<kbd>H</kbd> | Replace text in the selected names |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>H</kbd> | Append text to the selected names |
| <kbd>Ctrl</kbd>+<kbd>Alt</kbd>+<kbd>H</kbd> | Change the capitalization of the selected names |
| <kbd>Ctrl</kbd>+<kbd>B</kbd> | Change the budgets of the selected campaigns or ad sets |

## Navigate

| Keys | What it does |
|---|---|
| <kbd>↑</kbd> / <kbd>↓</kbd> | Row above / below (Properties follows) |
| <kbd>Home</kbd> / <kbd>End</kbd> | First / last row |
| <kbd>Page Up</kbd> / <kbd>Page Down</kbd> | A page up / down |
| <kbd>Shift</kbd> with any of the above | Select the rows on the way |
| <kbd>Alt</kbd>+<kbd>←</kbd> | Up a level: ads → ad sets → campaigns |
| <kbd>Alt</kbd>+<kbd>→</kbd> | Down a level, into the selected rows |
| <kbd>Ctrl</kbd>+<kbd>1</kbd> / <kbd>2</kbd> / <kbd>3</kbd> | Campaigns / Ad sets / Ads |
| <kbd>F2</kbd> | Edit the name of the selected row (in Properties) |

## Tabs, favorites and windows

| Keys | What it does |
|---|---|
| <kbd>Ctrl</kbd>+<kbd>W</kbd> | Close the tab |
| <kbd>Ctrl</kbd>+<kbd>Tab</kbd> or <kbd>Ctrl</kbd>+<kbd>Page Down</kbd> | Next tab |
| <kbd>Ctrl</kbd>+<kbd>Shift</kbd>+<kbd>Tab</kbd> or <kbd>Ctrl</kbd>+<kbd>Page Up</kbd> | Previous tab |
| <kbd>Alt</kbd>+<kbd>1</kbd> … <kbd>Alt</kbd>+<kbd>8</kbd> | Go to tab 1 … 8 |
| <kbd>Alt</kbd>+<kbd>9</kbd> | Go to the last tab |
| <kbd>Ctrl</kbd>+<kbd>D</kbd> | Add to favorites (the selection, or the view when nothing is selected) |
| <kbd>Ctrl</kbd>+<kbd>,</kbd> | Settings |
| <kbd>F1</kbd> | The list of shortcuts |

## Mouse

| Action | What it does |
|---|---|
| <kbd>Ctrl</kbd>+click, <kbd>Shift</kbd>+click | Select several rows; in the tree, add or remove a campaign or ad set |
| Middle-click a tab | Close it |
| <kbd>Ctrl</kbd>+click a favorite | Open it in a new tab |
| Right-click a tab or a favorite | Rename, duplicate, move, close… |

## Good to know

- **While you type in a box**, <kbd>Ctrl</kbd>+<kbd>A</kbd>, <kbd>Ctrl</kbd>+<kbd>Z</kbd>,
  <kbd>Ctrl</kbd>+<kbd>C</kbd>/<kbd>X</kbd>/<kbd>V</kbd>, <kbd>Delete</kbd>, the arrows, <kbd>Home</kbd>,
  <kbd>End</kbd> and <kbd>F2</kbd> work on the text. The others (<kbd>Ctrl</kbd>+<kbd>T</kbd>,
  <kbd>Ctrl</kbd>+<kbd>K</kbd>, <kbd>Ctrl</kbd>+<kbd>H</kbd>…) still work.
- With text selected in Properties (an id, for example), <kbd>Ctrl</kbd>+<kbd>C</kbd> copies that text.
- While a download or a push runs, only the keys that look around work (search, move, copy).
